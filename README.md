# Life-history trait coevolution across mammals, birds, and reptiles

This repository contains the data, R scripts, and saved analytical results for a comparative study of **life-history evolution in mammals, birds, and reptiles**. The analyses evaluate associations among five life-history traits while accounting for shared evolutionary history and body size. The workflow combines **phylogenetic generalized least squares (PGLS)**, **phylogenetic principal component analysis (pPCA)**, **phylogenetic path analysis (PPA)**, and **multivariate Ornstein–Uhlenbeck (mvOU) models** to investigate the structure and direction of evolutionary interactions among traits.

The R scripts are organized into three main stages: **(1) data preparation and phylogenetic comparative analyses**, **(2) multivariate evolutionary modeling**, and **(3) visualization of the main findings**. For the full biological interpretation, underlying data sources, and detailed methods, please refer to the accompanying manuscript.

## Data

The analyses consider three vertebrate groups independently: **mammals, birds, and reptiles**. For each group, the starting data comprise species-level life-history measurements and an associated phylogenetic tree. The main comparative analyses use five life-history traits corrected for body size using phylogenetic regression.

### Input files

| File | Description | Primary use |
| --- | --- | --- |
| `all_mammal_data.csv` | Original species-level mammalian data, including species identity, taxonomic order, body size, and life-history measurements. | Data preprocessing and phylogenetic trait visualization |
| `all_bird_data.csv` | Original species-level avian data, with corresponding taxonomic and life-history information. | Data preprocessing and visualization |
| `all_reptile_data.csv` | Original species-level reptilian data, including family and life-history information. | Data preprocessing and visualization |
| `last_mammal_tree.tre` | Mammalian phylogeny in Newick-compatible tree format. | PGLS, pPCA, PPA, mvOU, and phylogenetic visualization |
| `last_bird_tree.tre` | Avian phylogeny. | PGLS, pPCA, PPA, mvOU, and visualization |
| `last_reptile_tree.tre` | Reptilian phylogeny. | PGLS, pPCA, PPA, mvOU, and visualization |

### Life-history variables

| Abbreviation | Trait |
| --- | --- | 
| `BS` | Body size | 
| `OS` | Offspring size | 
| `DT` | Development time | 
| `AL` | Adult lifespan | 
| `CS` | Clutch size | 
| `CF` | Clutch frequency | 

The comparative analysis log-transforms the six numerical variables. For each of the five life-history traits (`OS`, `DT`, `AL`, `CS`, and `CF`), a phylogenetic regression against `BS` is fitted using a Pagel's-λ model. The residuals are then standardized (mean zero, standard deviation one) to produce the body-size-corrected datasets used in subsequent analyses. Species labels are used to align trait observations with the tips of the corresponding tree.

## R scripts

### [`LifeHis_PGLS_pPCA_PPA.R`](LifeHis_PGLS_pPCA_PPA.R)

Performs the initial comparative analyses separately for mammals, birds, and reptiles:

1. **Body-size correction:** log-transforms the traits, fits phylogenetic regressions of each life-history trait on body size using `phylolm` with the `lambda` model, and saves standardized residuals.
2. **Univariate evolutionary model comparison:** compares Brownian motion (`BM`), early burst (`EB`), Pagel's λ (`lambda`), and OU models with random or fixed root (`OUrandomRoot`, `OUfixedRoot`) using AIC and ΔAIC.
3. **Pairwise PGLS:** fits OU-based phylogenetic regressions for ten specified trait pairs within each taxonomic group, with bootstrap settings specified in the code.
4. **Phylogenetic PCA:** performs pPCA with a λ-based phylogenetic covariance model to summarize multivariate trait variation.
5. **Phylogenetic path analysis:** evaluates a set of 32 candidate path structures (`Model_0`–`Model_31`) using `phylopath` and an OU evolutionary model.

**Inputs:** `all_{mammal,bird,reptile}_data.csv`, `last_{mammal,bird,reptile}_tree.tre` (names expanded individually in the data table).

**Saved outputs:** `{mammal,bird,reptile}_data_corrected.csv`, `{mammal,bird,reptile}_PGLS_results.RData`, `{mammal,bird,reptile}_pPCA_results.RData`, and `{mammal,bird,reptile}_PPA_results.RData`.

### [`LifeHis_mvOU.R`](LifeHis_mvOU.R)

Uses multivariate OU modeling (`mvSLOUCH`) to investigate the evolutionary coupling among the five corrected life-history traits for each taxonomic group. It:

1. Rescales each phylogeny so its maximum root-to-tip height equals one, and orders the trait matrix to match the tree.
2. Reads the phylogenetic path-analysis results and translates candidate path structures into constraints on the mvOU **adaptation matrix (`A`)**.
3. Fits the candidate constrained models with a **diagonal stochastic matrix (`Syy`)**, using repeated optimizations and parallel workers. The primary candidate-model comparisons use **500 optimization iterations** per group.
4. Compares fitted candidates with **AICc** and identifies the best-supported structural model.
5. Enumerates alternative directions for interactions in the selected structure, constrains parameter signs using the best PPA model, and fits directional mvOU candidates using **100 optimization iterations**.
6. Extracts the selected model's adaptation matrix and eigen-decomposition/phylogenetic half-life summaries, providing information about directional coupling and longer-term evolutionary dynamics.

The workflow uses a two-stage fitting strategy, first fitting an unconstrained starting model and then fitting models with specified adaptation-matrix restrictions. 

**Inputs:** corrected data CSVs, tree files, and group-specific `*_PPA_results.RData` files.

**Saved outputs:** group-specific candidate-fit summaries and directional mvOU fit objects, described below.

### [`LifeHis_visualization.R`](LifeHis_visualization.R)

Produces graphics used to present the phylogenetic distribution of traits and fitted model results:

- **Phylogenetic trait overview:** integrates vertebrate phylogenies, geological time information, taxonomic groupings, and life-history measurements; writes `Figure2`.
- **PPA results:** summarizes model-averaged path relationships and displays estimated relationships and confidence intervals for the three taxonomic groups; writes `Figure4`.
- **mvOU results:** compares model-fit summaries for alternative stochastic structures and illustrates selected coevolution networks and directional-model outcomes; writes  `Figure5 a-c`.

## Intermediate model objects

Saved `.RData` files enable inspection of computationally intensive analyses without having to rerun all phylogenetic fits or optimization procedures. 

| Files | Contents | Associated analysis |
| --- | --- | --- |
| `mammal_PGLS_results.RData`, `bird_PGLS_results.RData`, `reptile_PGLS_results.RData` | Ten pairwise PGLS fit objects per vertebrate group. | Pairwise trait associations |
| `mammal_pPCA_results.RData`, `bird_pPCA_results.RData`, `reptile_pPCA_results.RData` | Phylogenetic PCA objects for the body-size-corrected traits. | Multivariate trait structure |
| `mammal_PPA_results.RData`, `bird_PPA_results.RData`, `reptile_PPA_results.RData` | Candidate phylogenetic path models and their model-fitting information. | Path-model comparison; input to mvOU |
| `Mammal_SyyDiagonal_OUOU_fit_niter500.RData`, `Bird_SyyDiagonal_OUOU_fit_niter500.RData`, `Reptile_SyyDiagonal_OUOU_fit_niter500.RData` | mvOU candidate-model fit statistics under diagonal `Syy`, evaluated over 500 optimization iterations. | Structural mvOU model selection |
| `Mammal_SyyUpperTri_OUOU_fit_niter500.RData` | Alternative mvOU results with upper-triangular `Syy`, loaded by the visualization script for stochastic-structure comparison. | Sensitivity/model comparison in Figure 5a code |
| `result_constrained_Model_6_mammal_OU_niter100.RData` | Direction-constrained mvOU fits for the selected mammalian candidate structure. | Directional coevolution in mammals |
| `result_constrained_Model_3_bird_OU_niter100.RData` | Direction-constrained mvOU fits for the selected avian candidate structure. | Directional coevolution in birds |
| `result_constrained_Model_10_reptile_OU_niter100.RData` | Direction-constrained mvOU fits for the selected reptilian candidate structure. | Directional coevolution in reptiles |
| `Model6_models.RData`, `Model3_models.RData`, `Model10_models.RData` | Candidate structural matrices loaded for network displays in the figure-generation script. | Visualization of candidate coupling structures |

**Interpretation:** `PGLS`, `pPCA`, and `PPA` outputs represent comparative results and fitted path models; `SyyDiagonal`/`SyyUpperTri` files store mvOU model-selection results; `result_constrained_*` files store fitted directional candidate models. These are **intermediate computational results**. The main visualization script can use them to regenerate downstream summaries without repeating each intensive optimization.

## Software

The analyses were written in **R**. Packages called directly in the three scripts include:

- **Phylogenetics and comparative analyses:** `ape`, `phytools`, `phylolm`, `phylopath`, `mvSLOUCH`, `PCMBaseCpp`.
- **Data handling, model processing, and parallel computation:** `dplyr`, `purrr`, `tidyverse`, `FactoMineR`, `foreach`, `doParallel`, `igraph`.
- **Graphics and figure assembly:** `ggplot2`, `ggtree`, `treeio`, `ggtreeExtra`, `paletteer`, `rphylopic`, `ggimage`, `ggnewscale`, `deeptime`, `ggpubr`, `patchwork`.
